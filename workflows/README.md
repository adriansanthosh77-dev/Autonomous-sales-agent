# Workflows

This directory is reserved for durable workflow definitions and Trigger.dev task mappings.

Recommended production workflows:

- `lead_enrichment`: enrich new leads, dedupe CRM records, and score fit.
- `follow_up_sequence`: schedule email, WhatsApp, and lifecycle touchpoints with suppression rules.
- `reply_triage`: classify replies and update the pipeline.
- `growth_optimization`: combine GA4, GSC, GTM, Ads, and Contentful signals into page and campaign actions.
- `lifecycle_journey_sync`: create or update Iterable journeys from CRM and product events.
